# Gemini Li · 付费运行期、离线与预算

只改 `server/app/m3/pulse/`、`server/tests/m3/pulse/` 和 `docs/reports/gemini-li-m3-wave2.md`。用 Fake 回调覆盖事件与知识模块，按 [本轮接口约定](../contracts/M3_WAVE2_API.md) 提供运行期接线。

1. 接通独立内存会话和复用有效叙事会话的控制入口。校验旅程、显式开关、模型绑定与会话有效期。关闭、解绑或退出只处理脉动持有的连接。重启和过期后等待重连。凭据不进入持久队列、错误回包、日志、用量、快照或导出。
2. 设计并实现在线闸门。前台触发续期，离开或切后台可立即失效，心跳缺失由可配置短租约兜底。核对请求前和提交前两道门，使用代次或同等机制阻止关开切换后旧结果提交。离线、暂停和未绑定时推进已确认时间锚，不积压可重演旧任务。使用确定性时钟测试断网、进程重启、重连、并发领单、过期任务与前台确认。
3. 用现有 OpenAI 兼容客户端和预算组件完成付费调用路径。调用前按上下文估算及输出上限预留额度，保留用途、调用数、实测或估算 token、可能计费的超时、冷却与按游戏日汇总。估算与上游实测有差异时以实测结算并约束后续调用。模拟用量与可能计费用量分开，预算不足时延后且无忙循环。
4. 交付安全状态 DTO 和控制调用样例，供集成方映射路由。锁内只做短数据库事务，网络和纯解析在事务外。用 Mock HTTP 覆盖正常 usage、缺失 usage、认证失败、响应丢失或超时，以及关闭后慢响应被丢弃的场景。任何测试不得请求真实供应商。

报告明确关闭、断网和 App 被系统杀掉时的可保证范围，区分阻止新请求、丢弃未提交的响应和已经发出的调用可能产生的费用。
