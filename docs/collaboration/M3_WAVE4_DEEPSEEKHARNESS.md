# DeepSeekHarness · 接线与组合验收

按 [任务索引](M3_WAVE4.md) 验证并分别导入三包，报告为 `docs/reports/deepseekharness-m3-wave4.md`。共享接线走组合分支，提交供 GPT 复审。

- 将分析入口连到现有资料导入和模型会话。应用草案时在同一事务写入实例、事件、人物和知识。返回给手机的摘要只含玩家应知信息。
- 将 NPC 模型推演接到既有脉动队列、预算及离线闸门。模拟深度与到期调度沿用 NPC 模块。提交事件、人物及传播时只推进一次实例版本，保持失败回滚和重试幂等。
- 以两份不同的普通导入资料走正式接口，验证「导入 → AI 分析 → 确认开局 → 推进时间 → NPC 行动 → 玩家再次遇见人物或查证消息 → 存档迁移后续玩」。两份资料分别更换地点与人物，测试从资料生成状态，避免用数据库预置人物替代初始化。
- 补测关闭与恢复脉动、旧存档兼容、自由行动、跨实例隔离和背景任务取消。运行全量 CI 和 Android 打包。真实服务商与安卓真机测试如有实际条件则分别记录，无法执行时列明缺项。发布采用推组合分支和 compare 链接的方式。
