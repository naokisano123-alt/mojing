# Gemini Marcin · 事件账本、初始局势与因果校验

先读[本轮入口](M3_WAVE1.md)和[契约](../contracts/M3_WAVE1_API.md)。你的模块同时覆盖 M3.1 和 M3.5 的因果数据基础。

## 本轮交付

1. **权威事件与版本历史。** 实现主要事件线、临时事件、到期分页读取、生命周期与追加式修订历史。以实例为隔离单位，事件更新用预期版本比较，单份提议失败就整体回滚。验证时间先后、生命周期转换、父事件引用、自引用与因果环。使用服务端分配身份和版本。
2. **AI 初始局势与事件推进。** 定义受限模型输入、结构化输出校验器和测试替身。初始化用本次授权的 Canon 来源产生 3～6 条活跃主线；后续从到期事件提议进展、停滞、终结、衍生临时事件。伪造来源、任意 JSON 路径写入、未来时间回填与直接更改玩家账本均应拒绝。
3. **因果可追溯。** 交付一个北境贸易 fixture。从邻国关税、商队改道到本地供应受影响，每个后果都有事件来源。对战争、政权更替等重大转折，先落实阶段和已登记前置条件的接口与测试。完整市场定价交给后续。
4. **集成快照。** 提供事件版本、因果和来源的可移植快照与恢复。至少能从同一个检查点恢复两个实例，对同一事件作不同推进。

## 文件和验收

拥有 `server/app/m3/events/`、`server/tests/m3/events/`。报告写 `docs/reports/gemini-marcin-m3-wave1.md`。实现契约中的领域入口，使用独立 SQLite fixture 及 Fake 或 Mock 模型。脉动调度、模型凭据、玩家认知投影、公共路由由其他模块处理。

验收要覆盖种子数量、来源伪造、过期版本、跨实例引用、因果环、合法完成后产生临时事件、同一提议部分非法时无写入、快照迁移。交包附一份可直接供集成测试使用的输入和期望输出。
