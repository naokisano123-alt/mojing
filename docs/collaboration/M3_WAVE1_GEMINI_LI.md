# Gemini Li · 异步世界脉动、队列与模型预算

先读[本轮入口](M3_WAVE1.md)和[契约](../contracts/M3_WAVE1_API.md)。在独立模块完成 M3.2 主体，以 Fake 回调代替其他团队模块。

## 本轮交付

1. **持久队列。** 实现任务登记、唯一幂等键、原子领取、带令牌租约、超时回收、重试退避、等待模型及取消。测试多连接争抢与重启恢复；旧 Worker 即使拿到模型响应也不能提交。连续回合可合并待办，已完成提交不重复处理。
2. **调度与游戏时间。** 默认关闭，支持启用、暂停和恢复语义。调度消费已确认游戏分钟，注入活动租约和实例快照检查；离线或会话失效不发付费请求，恢复时不补造暂停期间的历史。网络调用在 SQLite 写事务外，提交前重新检查实例版本和租约。
3. **模型用途与预算。** 世界模拟可独立连接或复用当前叙事会话，绑定只保存在内存。标准复杂度为默认，允许独立配置每轮调用、token、游戏日预算和冷却。用量标识实际或估算。覆盖请求前预算预留、并发扣额、超时与上游仍可能计费的情况。给出 Fake 和 MockTransport 集成示例。
4. **可观察性。** 提供脱敏任务状态和用量汇总接口草案。关闭脉动不影响前台叙事会话和既有历史；错误信息、任务数据库、存档与测试报告均不得含凭据。

## 文件和验收

拥有 `server/app/m3/pulse/`、`server/tests/m3/pulse/`。报告写 `docs/reports/gemini-li-m3-wave1.md`。交付可注入依赖的 Worker 与队列接口，提供 lifespan 接线示例，公共应用工厂、模型网关与端点由 DeepSeekHarness 接入。

验收至少覆盖相同任务只完成一次、租约过期后旧提交被拒、重启无 Key 时等待、独立与复用两种模式、离线暂停、前台在后台慢请求时可确认回合、后台旧版本冲突、预算耗尽延后及脱敏日志。
