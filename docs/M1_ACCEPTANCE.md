## 4. 已知限制（对外说明时不可省略）

- 不接模型、不收 API Key，真实世界不能驱动 AI 冒险
- PDF/DOCX 仅文本提取，无 OCR；扫描件直接拒绝
- 检索是字面子串，不承诺分词召回或海量性能
- 仅本地单用户，无鉴权，禁止直接暴露公网
- 线上站点仍是静态 M0 原型，后端能力只在本地可用
