# 墨境 · M0 手机端交互原型

一个使用本地模拟数据的 AI 文字冒险世界模拟器 UI。React 19 + TypeScript + Vite 6 + Tailwind CSS 4。项目独立创建，没有修改其他项目。

## 启动

推荐 Node.js 22.18+（测试使用 Node 内置 TypeScript 类型剥离）、npm 10+。

```bash
cd mojing-m0
npm ci
npm run dev
```

使用终端实际输出的 Local / Network 地址。Vite 默认端口 5173；手机与电脑在同一局域网时，可用输出的 Network 地址访问，且需允许该端口通过电脑防火墙。开发服务器仅用于本地开发。

```bash
npm run build   # TypeScript 严格类型检查及生产构建
npm test        # 模拟状态与分支测试
npm run preview
```

## 功能

- 我的世界：两张预置世界卡片、新建入口、继续冒险。
- 创建世界：名称和介绍表单、文件格式限制、文件名列表及移除。**不读取、不上传、不解析文件内容**。
- 冒险：小说正文、自由行动、快捷建议、模拟加载与停止、状态变化卡、小说/混合展示模式。
- 角色：体力、精神、铜币随模拟行动更新；背包、能力、公开背景及角色秘密。
- 图鉴：人物、地点、势力、世界规则，搜索和详情弹层、未发现档案占位。
- 时间线与存档：手动快照、恢复时创建新分支、切换分支、当前分支事件记录。
- 主页设置：阅读（主题、字号、行距、状态卡展示）、叙事、模型三个入口。主角光环仅在故事页右上角打开，不再混入设置。
- 手机适配：四个纯图标导航（图鉴为卷轴）、安全区、中文输入组合事件、Ctrl/Cmd+Enter 发送、跨页面保留输入草稿、停止模拟保留输入。
- 浏览器 localStorage 保存世界、回合、快照、分支和设置。无 Key、无真实 AI、无后端请求。

## 演示方式

预置世界和新建世界均采用统一的“雾港”演示模板；名称与简介独立，人物/图鉴/开局为预置内容，不代表从文档生成。

建议路径：进入雾港来信 → 输入“询问工作” → 角色中核对 22 铜币/74 体力 → 存档 → 建立分支 → 切换强力光环 → 再询问工作，观察增加的机会描述。

| 行动示例 | 模拟结果 |
| --- | --- |
| 询问工作 / 修补铜扣 | +4 铜币、−8 体力、40 分钟；体力不足时拒绝工作 |
| 买茶 | −3 铜币、最多 +5 体力；余额不足不扣款 |
| 坐下休息 | 最多 +15 体力、+10 精神，30 分钟 |
| 探索码头 | 在旧街/码头间切换，20 分钟 |
| 其他自由输入 | 记录输入并明确显示未判定结果，不声称理解任意行动 |

模拟以少量关键词匹配演示交互，不是自然语言理解、规则裁决或正式状态引擎。角色属性受 0–100 范围约束。光环改变机会文案，不修改历史回合和已有账目。

## 检查与限制

- `npm run build`：TypeScript 严格检查及 Vite 生产构建。
- `npm test`：余额持续性、余额不足、光环只影响未来、快照/分支隔离、未配置行动、休息上限和体力不足。
- 浏览器交互检查：新建世界、行动发送、状态反馈、保存/派生分支、图鉴详情、主题切换及导航。
- 通过 390px 手机视口检查和 320px 窄屏溢出排查。修复了滚动条占位时的最小宽度溢出问题。
- 尚未在安卓真机验证软键盘、旋转、系统字体和长时间游玩；CSS 安全区及 VisualViewport 适配需实机验收。
- 数据仅在当前浏览器，清除站点数据会丢失；草稿仅在当前页面会话内跨页面保留，不跨刷新保存。
- 存档、分支为 M0 客户端交互演示，不是 M3 事务引擎；未实现数据库、导入导出、云同步、账户或正式知识权限。
- 文档真实解析属 M1，真实模型与密钥属 M2，可靠状态机属 M3；PWA 安装、离线缓存、原生封装与正式性能/安全验证不在本轮。

## M0 第二轮：阅读优先交互调整

- 世界内隐藏品牌栏和设置入口；时间地点栏固定顶部。设置仅能从“我的世界”进入。
- 光环入口为右上角低对比四分之一圆，只显示星芒；展开后选择三档，下一回合生效。
- 删除 CHAPTER 01 和大块留白，保留紧凑的演示开篇标题，不模拟自动分章。
- 默认只展示可换行的行动建议与“…”；短按建议展开草稿，继续短按按换行追加，绝不覆盖手写文字。
- “…”打开自由编辑或已有草稿；收起保留，发送成功后清空并收起；停止模拟保留。超出 1000 字时拒绝追加，不截断旧内容。
- 自由行动仍是 M0 关键词模拟。多条建议合并为一条草稿；尚未具备依次执行复杂多动作的真实 AI 能力。
- 左滑依次为故事→角色→图鉴→存档，右滑反向。故事页连续右滑两次返回世界列表；世界列表连续右滑两次进入封面，封面提供重新进入按钮。
- 两次退出手势间隔必须小于 2 秒，超时、反向、点击、纵向滚动或页面变化取消确认；原进度不清除。
- 手势过滤多指、编辑控件、文本选择、弹层和垂直滚动；不接管系统边缘返回。鼠标或手指一次横滑需达到 58px、水平位移至少为垂直位移的 1.7 倍，并在 900ms 内完成。
- 底部保留点击切页；屏幕阅读器/键盘提供隐藏的返回按钮，聚焦时可见。减少动态效果偏好会停用切页动画。
- 原 localStorage 键和存档格式继续使用，字号/行距为可选字段，旧演示存档可直接继续。

### 本轮验证

构建与类型检查通过；共 11 项 Node 行为测试通过（6 项状态测试 + 5 项交互测试）。浏览器检查了输入展开/追加/收起、成功发送后收起、固定栏、主页设置分离、光环弹层、四页点击导航、封面与 320px/390px 布局。

远程浏览器的原生拖拽耗时约 5 秒，被手势过滤正确忽略；快速触摸滑动和 2 秒双滑退出目前通过纯逻辑测试验证，尚需安卓真机确认端到端手感。软键盘、系统边缘手势与旋转也仍需真机验收。此次不引入 M1–M4 正式能力。

### 图鉴滑动修复

图鉴卡片、分类按钮及其图标支持从其上起手横滑切页，轻点保留原功能。输入框、弹层和明确独占手势的区域仍保留各自操作。手势通过捕获阶段识别，横向拖动后消费浏览器的合成点击，避免同时打开详情；未发现卡片也可作为滑动起点。回归测试直接执行实际手势处理器，覆盖按钮、分类条、图标、普通内容、轻点和输入框，共 17 项测试通过。实际安卓触摸手感仍需真机复核。

## 后端（M1 资料库）

`server/` 是 FastAPI + SQLite 的本地后端，提供：世界持久化、TXT/MD/PDF/DOCX 导入与分块、原文与来源定位、中文子串检索、人工设定条目（草稿/确认、revision 乐观并发、来源引用与失效提示）。**不接模型，真实世界不能驱动 AI 冒险。**

- 契约：[M1_AB_API](../contracts/M1_AB_API.md) v0.2 → [M1_R2_API](../contracts/M1_R2_API.md) 1.0-r2 → [M1_R3_API](../contracts/M1_R3_API.md) 1.0-r3 → [M1_R4_API](../contracts/M1_R4_API.md) 1.0-r4（逐轮追加，旧端点不变）
- 代码：`server/app/{main,db,config,importer}.py`、`parsers/`、`import_policy/`、`lore_search/`、`lore_entries/`

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r server\requirements.txt -r server\requirements-parsers.txt
cd server
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

前端开发期由 Vite 代理 `/api` → `http://127.0.0.1:8000`，无需处理跨域。

测试（后端）：`cd server` 后 `..\.venv\Scripts\python.exe -m pytest`。
测试（前端逻辑 + 组件）：根目录 `npm test`（node:test）与 `npm run test:ui`（Vitest + jsdom + React Testing Library）。

限制：PDF/DOCX 只做文本提取（无 OCR）；搜索是字面子串、不做分词；线上未部署 Python 后端，本地闭环不等于线上可用。M0 演示数据（localStorage `mojing-m0-v1`）与后端 SQLite 完全隔离。
