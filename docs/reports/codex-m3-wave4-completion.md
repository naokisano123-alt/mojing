# M3 第四轮接手与验收

本轮基于 `9117404aa307c53de235b2959507d8d577d9fbca`。Li、Marcin、Ma 的三份交付分别验收并提交，文件数依次为 9、14、8。31 个路径及 SHA-256 均与各自的 manifest 一致，三包之间无同路径变更。后续接线和修复集中在独立提交。

## 可玩入口

- 在任意自建世界导入资料，打开「冒险记录 → 从世界资料生成开局」。选择本世界的文档或已确认人工设定，填写角色、起点和世界时间。真实模型模式复用已连接的模型会话，由玩家主动发起分析。
- 分析按起点挑选相关资料并分批发送。预览展示玩家可见的地点、人物、消息和资料来源，标出补写与冲突。确认后在同一事务中建立旅程、世界事件、NPC 和知情记录。确认可以安全重试，放弃草案不会写入正式账本。普通冒险入口可直接开始。
- 正式旅程里可启用世界脉动。确认推进时间后，模型根据到期人物、当前动机、各自已知的事实与事件提出行动。提交继续走现有在线租约和费用预算。下一回合读取当前人物状态，查证入口同时按当前位置判断是否可接触。
- 检查点和 ZIP 迁移沿用现有领域快照。分支从检查点恢复。重新分析开局会建立独立旅程。

## 已验证

| 验收项 | 结果 |
| --- | --- |
| 两套 Markdown 经正式上传接口导入 | 云泽水驿与赤霄机关城分别生成自己的起点人物。只选择文档时，未选的人工条目不进入分析。 |
| 草案写入边界 | 确认前旅程、实例、事件、人物和知识表均未新增记录。跨世界确认被拒绝，放弃后不再出现待确认草案，同一草案重复确认返回同一旅程。 |
| 真实模式接线 | 用 HTTP 模型替身验收模型会话复用、草案确认、推进时间、世界脉动、NPC 出行和事件更新。同一脉动事务只推进一次实例版本。 |
| 可玩影响与迁移 | NPC 离开水驿后从同地查证名单移除，随后叙事能读到其已离场。ZIP 导入另一数据库后，新旅程保留旧回合及该 NPC 的位置，并可继续生成和确认回合。 |
| 兼容入口 | 无资料可直接开普通模拟旅程。事件独立推进与现有前后端测试仍纳入回归。 |

## 验收边界

- 模拟模式用本地规则生成分析演示。AI 自主调度走正式旅程中启用的世界脉动。
- 分析使用有上限的相关节选与分批计划。长资料的实际覆盖随所选来源、起点和截取预算变化。
- HTTP 测试替身验证调用与数据流。真实服务商输出质量、费用和 Android 真机交互需单独验收。
