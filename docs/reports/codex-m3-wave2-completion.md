# M3 第二轮集成复验

以 DeepSeekHarness 的组合分支 `7dec972` 为基础，保留三个 Gemini 原始提交。本轮补齐实际入口并以 HTTP Mock 复验正式旅程。

- 正式旅程可在冒险记录展开「世界脉动设置」，分别配置独立模型或复用当前叙事会话。连接与启用分离，默认关闭。沿用安卓 HTTPS 与托管允许地址限制。
- 租约来自前台活动。返回旅程和重新联网时续期，切后台或离开时尝试结束。正式旅程的确认回合将租约和会话闸门纳入入队判断。重启后等待重连。
- 付费链路采用事件域的受限提示词，预算估算以实际准备发送的文本为依据。正式叙事只使用玩家已获知的投影。后台权威信息和其他实例内部字段不发给玩家叙事模型。
- HTTP Mock 覆盖两种连接方式、离线闸门、初始局势、到期事件、公告、叙事回读、关闭后续玩、重启重连和模型地址限制。首轮模拟演示及迁移回归继续执行。

## 安卓手动验收

1. 安装新 APK，导入世界资料，新建正式旅程。先在普通模型设置配置叙事连接。
2. 展开「世界脉动设置」，选择独立模型或复用叙事会话。确认启用前没有后台调用。
3. 启用后等待初始化。确认一个推进时间的行动，到期且存在传播渠道时，在「世界消息」刷新可见消息。继续生成一回合，核对叙事只使用已经知道的消息。
4. 切后台、恢复、关闭和重新连接各试一次。检查正常叙事仍可继续，并确认预算区和服务商记录可分别识别脉动用量。

真实服务商、安卓真机及线上部署需单独验收。完整 M3 迁移的已删除来源限制保留至第三轮处理。
