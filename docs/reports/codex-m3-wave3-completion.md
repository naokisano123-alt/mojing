# M3 第三轮组合验收

组合验收覆盖从商队改道、NPC 离开、玩家查证到导入后继续冒险。测试用正式资料导入与事件账本建立北境场景，在已确认的游戏分钟调用 NPC 领域服务，再通过应用的查证与 ZIP 迁移接口完成余下流程。

- 查证引用事件账本中的真实事件，确认后写入正式知识账本。草案与确认分别校验地点、游戏时刻和实例版本。出行的 NPC 不会在当前地点出现，玩家也不会从界面得知其去向。
- 「世界消息」已接入查证面板。选项可以填入行动编辑框，查证草案经玩家确认后刷新消息。查证沿用独立草案与确认接口。
- 原资料删除后，事件与 NPC 历史引用一同迁移。已删除来源仍留作历史凭据。导入后旧检查点可恢复，确认前的分支只看到当时的传闻。
- 先前跳过的用例中，事件 ID 与查证引用不一致，章节路径也被手工写成空字符串。现在使用同一正式事件标识与真实资料导入接口，保留对损坏迁移文件的校验。

NPC 的存储、行动规则、查证联动和迁移已通过组合测试。新建自定义世界的 NPC 初始化与后台自动调度仍待接入，组合测试通过固定场景给 NPC 提供初始数据与行动提议。真实模型服务商与 Android 真机的游玩体验需分别实测。
