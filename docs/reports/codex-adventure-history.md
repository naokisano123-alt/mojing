# Codex 独立开发：连续冒险记录

基线d00201120165ea25a53cb553317a58f740431245。本轮独立实现M2-B第一阶段：持久化旅程、待确认草案、幂等确认回合与历史上下文。

- SQLite幂等新增adventures/adventure_drafts/adventure_turns；每个旅程固定Fake或Live。
- 短事务预留唯一请求ID；同ID重试不重复模型请求，生成在数据库连接关闭后进行；失败/断开只改变草案状态，不追加回合。
- 明确确认按钮原子追加叙事并递增版本；重复确认幂等，旧版本草案冲突拒绝。pending90秒后可恢复，ready草案刷新可见。
- 最近6个已确认回合进入独立历史字段，UTF-16节选预算，不将未确认内容当成世界事实。
- 资料库新增“冒险记录”，支持新建/切换旅程、历史分页、生成/停止、恢复/丢弃/确认草案。复用内存模型会话，不重复填写Key。
- M0存档、人物属性、财物和时间均不迁移或结算；正式世界状态引擎尚未实施。未做云同步、导出或原生App。

测试：真实SQLite/HTTP幂等、并发冲突、重启持久化、世界软删、过期pending、真实Live mock历史传递、重复在途请求只有一次上游调用、真实ASGI断开；React覆盖必须确认才写入、停止保留行动、确认失败同ID重试。本地完整检查：后端261通过、前端逻辑62通过、React组件28通过，TypeScript/Vite构建通过。仓库CI另验证Node22/Python3.11。

本轮未使用真实Key/付费服务商、未部署、未安卓真机测试。上一阶段浏览器进程受环境限制无法启动，本轮不将组件测试称为端到端真机验收。
