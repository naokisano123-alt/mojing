# Codex 独立开发：背包账本

起点aac388b43968d4699ee4786eff317f1139072e6e。为新旅程提供起始背包编辑，角色卡与历史快照显示物品数量；模型上下文包含当前背包，状态提议扩展inventory_changes。

程序校验归一名称、数量、容量、扣减余额、重复项与字段白名单；默认不采用，确认后物品/铜币等同事务保存。状态提交、去重、旧版本冲突、重试和取消沿用已有链路。旧角色缺inventory字段按空背包兼容，无新表或强制历史重写。

Fake提供明确的固定测试物品示例；真实模型仍需用户配置Key。程序不处理装备/耐久/唯一实例/品质，也不判断交易或掉落的合理性。

本地完整检查：后端302通过、node:test62通过、React组件34通过、TypeScript/Vite构建通过。新增Live MockTransport的物品+铜币确认/重启、并发只扣一次、无效提议整份拒绝、容量/数量/Unicode名称、起始物品编辑与显式采用组件测试。未调用真实付费模型、未部署、未安卓真机验收。
