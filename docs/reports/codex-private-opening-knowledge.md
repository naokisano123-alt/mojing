# 开局私密委托与玩家认知修复

2026-11-12。基线 main 09e4daf，修复真机截图中“送达羊皮纸 visibility=secret，不能在开局标记为玩家已知”的阻断。

原因是初始化校验将事件公开程度与玩家是否知晓绑在一起。秘密委托可以对公众保密，同时被当事角色明确知道；知道委托不等于知道信件内容、幕后原因或未来送达结果。

事件增加可选 player_known_basis。秘密或势力内部事件的玩家认知，必须有玩家确认的开局描述中的逐字依据；只向玩家投影该段依据，使用中性标题及亲历渠道，不暴露后台事件说明或模型自造的泄密标题。明显包含“你不知道、殊不知”等未知语义的所在句不作为亲历证明。依据缺失或无法核对时，仅保留后台事件，记录 withheld_ungrounded_player_knowledge，不因为模型的矛盾标注阻断整段开局；玩家填写的完整开局文本仍保留。公开程度本身不被改成public，也不自动为NPC增加认知。

私密认知不会直接改变任务进度、完成事件或结算财物。正式公开信息、NPC私密动机、跨世界来源等原有边界继续校验。新增字段可序列化并重新校验，已落库的玩家认知沿用原迁移格式，不需要改数据库表。

本地全量后端488项测试和5项子测试通过，生产构建通过。新增测试覆盖秘密委托、隐藏背景隔离、泄密标题替换、没有依据、明确未知、伪造依据、序列化重验，以及经过实际开局路由、三域初始化、玩家消息、ZIP迁移的完整链。模型传输使用Mock，未使用用户的真实API Key，未进行安卓真机回测。

限制：自然语言中的认知与否定语义无法只靠关键词完整判断，仍需要模型遵守提示和玩家开局描述；这里增加的是可核对的投影依据与保守降级，不宣称能形式化验证任意中文叙事。遇到明确全知背景，请放入世界观文档，将玩家开局描述用于角色当前处境。
