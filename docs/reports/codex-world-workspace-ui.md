# 世界界面与文档编辑

进入世界后的主栏目收敛为「冒险」「世界观文档」「设置」。世界名称与介绍缩短排版，主栏目在滚动时保留入口。

世界观文档集中管理导入文档、人工设定、搜索和导出。文档列表的标题可直接阅读，章节索引和删除收进每份文档的操作菜单。顶部搜索同时查询文档与人工设定，清空后恢复列表。导出菜单内提供世界观、存档和完整 ZIP，Android 端仍可导出两份文件。

模型连接、当前旅程的世界脉动、阅读偏好与叙事偏好归入设置。冒险页通过书签图标管理存档与分支。切换三个栏目时保留旅程组件与未发送的行动，脉动的活动租约继续跟随旅程与应用前后台状态。

## 编辑

导入文档与人工设定详情提供笔形编辑入口。进入编辑后可点眼睛保存并切回只读。关闭有改动的文档查看器也会先保存，失败则保留编辑内容。

PDF、DOCX 编辑的是提取后的正文，不回写原文件的版式。保存会更新当前文档并重新生成检索切片。旧切片及对应原文保留为历史版本，原有引用显示需要复核。版本检查使用读取时的内容 SHA-256，过期编辑不会覆盖其他页面的修改，重复保存相同内容不会反复归档。修改后的文字可检索、可供新叙事使用，也会包含在迁移导出中。
