# 手机阅读与旅程存档重整

按本轮《修改建议.docx》的文字及五幅标注图实施。工作分支 feat/journey-redesign，基线 main 的 46f17a1。

## 本轮结果

- 去掉世界内重复标题与说明，收紧顶部空白；地点与粗略时段固定在阅读顶栏。冒险、世界观文档、设置移至底部，存档归回冒险入口。
- 正式故事采用羽笔、你的行动标注和侧边强调样式；回合分隔在行动之后，正文去掉大块卡片边框。
- 旅程文件夹和存档分开列出。当前旅程优先，进入后自动存档在前，手动存档在后；可命名旅程、命名手动存档、删除手动存档、读取或以存档建立另一旅程。
- 创建及每次确认回合更新唯一自动存档。20个手动存档上限、请求重试及跨旅程校验由后端事务保证。历史、记忆及各领域快照完整恢复，旧运行历史不被覆写。
- AI推荐与自写合为同一开局编辑器；候选可写入并继续修改。角色、位置、物品介绍、数量和属性均可在自然语言中表达。开始时理解最终文本，有资料时继续创建原有事件、NPC和认知账本；任何一步失败不留下半成品旅程。
- 修复无有效交谈目标导致整份开局被拒绝：暂缓该对话为等待任务并记录处理原因，不任意补造对象、不关闭正式领域校验。
- 安卓原生导出入口支持所选旅程参数及保存窗口，并用实际Java执行测试覆盖合法与非法下载参数。
- 新建世界先整理世界观文档。文档内集中管理导出，可全选或选择完整旅程；同世界版本可在存档管理底部导入旅程。
- 修复选择性导出、迁移身份映射、同世界导入含物品介绍及仅存档文件的兼容问题；原本的设备隔离与独立副本导入继续保留。

本地最终结果：后端482项及5项子测试通过；前端Vitest 83项、Node 77项，共160项通过；TypeScript及Vite生产构建通过。最终CI还会复核。新增后端场景覆盖自动/手动存档、20个上限、同旅程读档、以存档建立新旅程、选择性ZIP迁移、同世界导入、错误世界版本与恶意元数据回滚、最终开局文本的模型输入、请求幂等、NPC/事件领域初始化和缺失交谈对象。前端覆盖底部栏目、首次文档准备、同一开局框编辑与重试、旅程排序及存档请求幂等、正文草案跨栏目保留、ZIP续玩后重进世界。

没有使用真实服务商 Key，没有 Android 实机回测。本机 Chromium 因系统禁止创建 socket 而无法启动，因此不把 DOM 测试称为截图或真机验收。APK 由 GitHub Actions 构建，下载后核对压缩包和内嵌网页资源。
