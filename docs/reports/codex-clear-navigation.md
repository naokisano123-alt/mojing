# 四栏目与冒险阅读整理

基线：`8007dd04e91f5d64da12f980cd119e0055356686`，本轮按用户确认的功能归属整理，未委派其他 AI。

## 唯一归属

| 栏目 | 职责 |
| --- | --- |
| 冒险 | 当前正文、行动选项、输入与确认；顶部按需打开角色和消息 |
| 存档 | 旅程新建/切换、保存/恢复、分支；存档导出及完整备份 |
| 世界观文档 | 文档导入/浏览/编辑/搜索、人工设定、设定导出 |
| 设置 | 阅读/叙事偏好、模型连接、世界脉动、开局与日程配置 |

冒险页去掉旅程下拉、重复标题、Live/Fake 技术标签、累计确认回合标签、存档按钮与常驻刷新按钮。无旅程时仅提供“开始冒险”，跳转存档创建；创建或读档完成后自动回到正文。刷新进度与草稿恢复归入存档，正在等待的故事保留查询结果入口。

`AdventureJournal` 仍只有一份状态，按当前栏目呈现阅读或管理；输入和待确认故事不会因栏目切换被丢弃。设备偏好只记录按世界隔离的当前旅程 ID，恢复时校验世界归属，失效或已删除的旅程回退到最新旅程。补齐分页偏移，避免记住的旧旅程影响列表翻页。栏目记忆各自滚动位置，新建/恢复返回阅读起点。

## 角色、消息和日志

- 角色改为顶部按钮打开的原生 dialog 面板；支持关闭、Escape、滚动约束、原按钮焦点恢复。正文不再放置当前角色卡。所有角色卡和开局编辑器移除固定体力/精神仪表。
- 新增 `condition` 文字近况，500 字以内；真实模型的当前状态输入去掉固定体力/精神数值及其增量要求，使用有依据的文字近况更新。确认、历史、检查点与分支保留近况，钱币和物品数量继续精确记录。原 JSON 的数字字段兼容读取，不作为真实叙事的通用身体规则，也没有增加旧模式开关。
- 消息面板按需加载，只保留一份可筛选、可翻页的消息列表；点击具体消息的查证入口再展示相关选项。查证编辑与主行动输入共享草稿，可直接带回冒险编辑并聚焦输入框；查证确认后刷新主故事，避免正文修订落后。
- 全局“世界日志与更正”移至正文、草稿及行动输入之后，默认折叠；历史回合里的变更说明仍可单独展开，保留追溯能力。

## 远景反馈

- 公共脉动状态新增 `simulation`，根据实际已保存的事件判断初始化成功，不依赖会话就绪或 Token 用量。模拟正在执行或失败时，已有事件标为“已保存的远景事件”，不冒充当前请求成功。
- 同一次事件提议可携带独立 `public_label`：简短、模糊的意象代称。提示词禁止人物姓名、具体地点、计划、秘密和结局；代称不是角色知识。公共 DTO 只投影种类及该代称，不直接使用内部标题和说明。
- `world_events.public_label` 幂等迁移；字段经过校验、事务内复核、保存、更新继承、版本快照及恢复。已有无名事件使用“未明的动向”，正常推进时允许模型补名，不额外发起命名请求。
- “大事件”对应持续事件线 thread，“小事件”对应临时事件 incident，并不限定事件必须发生在宏观政治领域。
